# 家庭账本篇插画

五张图片于2026年11月16日使用内置图像生成工具创建，为本游戏的虚构生活插画。没有使用同事模拟器的图片，也未将这些画面标成新闻照片。

统一方向为温暖的手绘水彩与纸张质感、宽幅生活场景、无界面文字、无品牌标识。制作时分别描述家庭整理预算、收到工作机会、整理长辈遗物与存款、裁员后带纸箱离开、家人核对账单五个场景。交付仅做1200×675尺寸适配及WebP编码，没有通过代码重画图像。

| 文件 | 游戏用途 |
| --- | --- |
| story-family.webp | 首页与家庭节点 |
| story-career.webp | 换工作与重返工作 |
| story-inheritance.webp | 继承遗产 |
| story-layoff.webp | 裁员 |
| story-quiet.webp | 个人生活与财务危机 |

图片预先生成并随静态网站发布。游戏运行时不调用图像API，不包含密钥。每幅图在页面标注“AI绘制 · 虚构生活情境”。
