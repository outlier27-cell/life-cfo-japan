# 人生 CFO 日本篇

[公开试玩](https://outlier27-cell.github.io/life-cfo-japan/) · 2.0 七年篇 · 1988 年末至 1995 年末。

玩家从 24 岁、100 万日元开始，经历 7 个年度、14 次生活与资金决定。夜校、住房、家庭保障、工作中断与共同目标会留下持续影响。历史行情只显示到游戏当前时点。结局提供同背景、同意外、同生活决定的单次现金比例对照，不用期末财富给人生排总榜。

## 游玩和分享

无需注册。每次选择自动保存在本机浏览器，可以从「存档」导出 JSON 到其他设备，再导入恢复。两份有效存档轮换保留备份。多个标签页同时改动会提示刷新，避免无声覆盖。旧版单年试玩记录不会删除。

可以复制同场邀请。链接中的 `seed=1989&family=family` 指定人生编号和家庭背景，朋友会遇到同一组外生意外，但做出自己的选择。结果只保存在各自设备，当前没有云存档或线上排行榜。期末年报可下载为文本。

## 本地运行

无需安装依赖，使用 Node.js 20 或更高版本：

```powershell
node ./life-cfo/serve.cjs
node --test ./life-cfo/engine.test.cjs ./life-cfo/charts.test.cjs ./life-cfo/rules.test.cjs
node ./life-cfo/build-offline.cjs ./output/life-cfo-japan.html
```

服务默认端口 4173，通过 `LIFE_CFO_PORT` 可以覆盖。添加 `--lan` 后可在同一网络通过电脑 IP 试玩。离线单文件 HTML 内嵌图片与代码，须用可执行 JavaScript 的浏览器打开。

## 模型和数据

- 8 个历史观测点：1988–1995 日经 225 年末价格，来源为[日本内阁府经济社会综合研究所](https://www.esri.cao.go.jp/jp/esri/prj/sbubble/yearly/yearly.pdf)与[日本证券业协会 Fact Book 1999](https://www.jsda.or.jp/shiryoshitsu/toukei/factbook/files/efb1999.pdf)。指数名称和权利归 Nikkei Inc.；折线为本作品自行绘制。
- 角色、收入、费用、保障合同和意外是教学模型。全年收支在年末结算，无法表现年内流动性压力；现金收益为零，不计股息、税费、交易成本与债务利息。
- 每年顺序：生活即时费用、资产再分配、年末估值、收入减必要支出、意外自付。现金不足时卖出股票，不足部分记未付款。未来收支结余优先偿还。
- `engine.js` 是可重放的纯规则；`content.js` 保存剧本、历史点位和版本；`charts.js` 生成原生 SVG；`app.js` 负责会话与交互。存档只保存命令，导入后从规则重算资产。
- 同种子意外按年份独立生成，选择不会改变之后的抽签结果。对照只替换一年的资产分配，后续保持相同命令。它用于解释同一历史中的后果，不预测未来收益。

主流程不依赖外部字体、SDK、模型 API 或第三方跟踪；打开史料链接时才离开站点。东京插画由内置 Image Gen 创作，源提示为晚昭和东京街景、上班族、列车和暗红落日，沿用 1.0 图片。

## 发布与验收

GitHub Pages 从独立仓库的 `main` 发布。上传白名单为 `index.html`、`style.css`、`app.js`、`content.js`、`engine.js`、`charts.js`、`tokyo-1989.webp`、`.nojekyll` 与本文。代码目录中的临时文件和本机存档不发布。前一版本提交可以回退。

规则验收覆盖 25,856 个完整组合（2 种背景 × 128 条生活路线 × 101 个现金比例），检查每年资产守恒、无负持仓、存档重算、输入保护、延迟效果及反事实一致性。浏览器还需检查 7 年通关、刷新续玩、导入导出、曲线对照、损坏存档恢复和 320/390 像素窄屏。所有测试使用虚构模型，不能替代目标用户的可玩性与教育效果试验。
