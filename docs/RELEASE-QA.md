## 交付边界

好友榜是用户选定的成绩链接汇总，不是云同步；没有身份认证或竞赛级防作弊。四国年度教学模型不等于真实金融产品回测，收入/支出/家庭事件为虚构参数。技术验收不能替代老师与同学的真实体验、教育效果研究或具体发行渠道审核。

公网版本在推送 GitHub Pages 后另行核对资源、完整流程与跨上下文成绩链接。
