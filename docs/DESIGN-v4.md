# 4.0 界面与交互验收

2026-11-13。沿用3.0的纸质账本设计体系，新增内容以本轮明确要求为边界：四金融仓位、独立保障/房车计划、年度消息、执行规则和多模型比较。

## 保留的设计与新增组件

概念基准为既有 `output/life-cfo-v3-design.png`；主视觉继续使用原创旅行账本 `world-journal.webp`。沿用暖纸背景、深红主按钮、宋体标题、清晰的正文、Georgia数字与细边框。新增债券采用蓝色、黄金采用金褐色，现金和股票沿用橄榄绿与深红。

配置页先展示上一年的消息与观测，再展示目标比例。执行纪律和家庭安排默认折叠；确认之前展示实际执行单和无法执行的购买计划。报告先比较玩家与三种规则模型，再展开人生与年度细节。

这轮没有重做无关的首页视觉，也没有添加虚构排名、捏造业绩或将房地产和保险画成与股票相同的收益滑条。

## 浏览器方法与修复

沿用上轮的内置浏览器不可用回退：Edge实际点击前两年，再以隔离Playwright Chrome完成60次流程及异常、分享和响应式检查。未将模拟视口宣称为实体iPhone或微信内置浏览器认证。

验收发现并修复：页脚旧版本号；手机全模型宽表难以发现后续列；平局显示“高0、费用多0”；零负债显示负零。手机对照改为下拉选择模型与自己逐行比较，320/390px无需横向滚动，桌面保留全部模型。

截图证据使用 `v4-` 前缀保存在交付工作区可视化目录。主代理已用 `view_image` 并排检查既有概念图、最终390px配置页（v4-allocation-final.png）和完整报告（v4-report-final.png），以上五项对照均保持一致。所有示例数字为测试局的实际计算结果；剧情对白明确标记为虚构。与既有概念相比，信息结构的改变对应本轮新增功能，未发现阻塞使用的视觉问题。
