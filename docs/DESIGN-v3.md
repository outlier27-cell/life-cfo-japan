# 全球篇设计与验收基准

2026-11-13。沿用已上线的纸质账本风格，增加全球出生、连续 60 次选择、三十年回顾、成绩链接好友榜与网页版玩法说明。

设计概念：`output/life-cfo-v3-design.png`。主视觉使用内置 Image Gen 生成的原创旅行账本，制作提示：四个城市的水彩旅行手帐、暖色纸张、钢笔与指南针，无文字、无商标。生产图片 `world-journal.webp` 为该原图的网页压缩版本。

## 组件与呈现

- 背景 #f5ecdc；文字 #281b14；主操作 #852d26；现金 #686746；对照 #37596b；细边线 #c7b49b。
- 中文标题宋体回退，正文系统无衬线，数字 Georgia；手机正文 15px，标题 28–32px，主要按钮至少 48px。
- 手机单列，桌面最大 1000px 双栏；主页插画保持 16:9；无模拟手机状态栏。
- 顶栏品牌、玩法、好友榜。游戏内底部账本、史料、存档为真实可用入口。
- 一次展示一个核心决定。生活决定与配置决定分成两步，明确 1–60 进度。结算有独立页面，长明细折叠。
- 概念中的数字和姓名仅为设计示意，实装使用规则计算的真实当前状态。好友榜无成绩时必须显示空态，不放假玩家。
- 将概念误写的“日经年末收盘”替换为 OECD 12 月股价指数；四国组合明确是教学组合。实际购买力注明基年，坐标按真实数据绘制。
- 起始角色不使用概念中的性别固定头像；出生卡以地点、出生年、家庭背景呈现，确保身份信息与随机结果一致。

## 体验路径

随机出生 → 看懂开局 → 每年生活决定 → 资产安排 → 年度结算 → 30 年回顾 → 改一次配置比较 → 分享成绩 → 汇总同开局好友榜。

经典日本七年篇保留独立入口与旧存档。新版存档固定规则、内容和数据版本，不强行迁移旧规则。

## 验收记录

2026-11-13，本地实现与概念图已直接用 `view_image` 对照。浏览器验收先尝试内置浏览器；因 IAB 不可用，改用 Edge 实际交互，并使用隔离的 Playwright Chrome 上下文补充完整流程、异常与响应式检查。

| 核对点 | 实装检查结果 |
| --- | --- |
| 信息层级与文案 | 保留“60 次选择，经营你的人生”、四国三年代、30 年/60 次/同场对照、出生卡与开始按钮；首屏核心文案无语义偏移。补充教学参数和支持国家说明，避免误读 |
| 版式与响应式 | 390px 原生截图对照，320/390/1280px 全流程无页面横向溢出；手机单列，桌面限制内容宽度，表格可局部滚动 |
| 字体与数字 | 标题宋体、正文清晰、数字单独呈现；报告金额、单位、基年、现金月数均可辨认；不把概念中的虚构金额当实测结果 |
| 配色与组件 | 暖纸底、深红主按钮、橄榄色现金、蓝色对照线、细边框与账本式导航一致；表单、选择与折叠状态可以实际操作 |
| 视觉资产与数据图 | 原创旅行账本保持完整 16:9 构图；真实曲线有纵轴、年份、图例和数值表。报告的两条线由同场回放生成，接近时不人为拉大差距 |

有意调整：移除固定男性头像、样例好友与错误的日经标签，改为真实身份和空榜；生活与配置分屏，年度结算单独确认；反事实设置放在报告主图之前；完整日志与史料折叠，以适应手机阅读。以上调整服务于已明确的随机身份、准确数据和简单操作要求。当前未发现阻塞使用的视觉偏差，不将概念里的示意数据或构图当作逐像素复刻承诺。

修正的实际问题：首次进入报告自动选择一个不同的现金比例，避免默认两条曲线完全重合；减少长报告默认展开的信息；截图在字体就绪、动画关闭后拍摄，避免入场动画造成发灰误判。

核心路径已完整走通：出生 → 60 次选择 → 30 次年度结算 → 回顾 → 单次配置比较 → 分享 → 新浏览器导入成绩 → 同场好友榜。补测存档备份、坏档导入、多标签冲突、写入失败、离线首年结算和经典日本篇。
