# 《人生 CFO》完整改进分析与交付范围

全球篇 3.0 · 2026-11-13

## 结论：核心应是连续决策后的因果回顾

本轮对照了用户提供的《中国式人生小游戏调研与开发方案》、已经上线的日本七年篇，以及全球出生、60 次选择、真实历史数据、简单手机操作、好友比较的明确要求。

“只有一次选择”的反馈指向最初的单年玩法。七年版已经补了连续决策，但它仍然不足以表现长期责任、物价变化、不同经济环境和完整好友比较。本轮以“随机出生 → 30 年连续选择 → 账本结算 → 三十年回顾 → 同场好友榜”为完整网页交付闭环。

用户已明确选择先用成绩链接汇总好友榜。因而本版不伪装成自动联网同步，也不把浏览器本地存储称作云端数据库。

## 旧版问题、影响与本次处理

| 问题 | 为什么影响体验或可信度 | 本次处理 |
| --- | --- | --- |
| 时间仅七年、选择数量少 | 很难看到早期投入与长期责任的回收 | 延长为 30 年、30 个生活节点加 30 次资产安排，共 60 次选择 |
| 只体验一个国家和一段行情 | 容易把这一段历史的有效策略误认成普遍答案 | 4 国 × 3 个历史起点 × 3 种家庭背景；随机开局，分场比较 |
| 生活选择之间的联系不够强 | 事件像问卷，确认后就被遗忘 | 技能、住房、伴侣、孩子、保障、互助和维护有持续效果与条件分支 |
| 现金与股票之外缺少分散体验 | 难解释本地集中与跨国风险的差异 | 增加四国等权教学股票组合，纳入本币汇率变化，不承诺分散能保本 |
| 长期账本不考虑物价 | 名义金额增加容易被误读为购买力增加 | 增加真实 CPI 调整、购买力曲线及随已知 CPI 变化的教学预算 |
| 各国历史数据口径可能混乱 | 日终收盘、月均值、价格回报与含股息回报会产生不同结果 | 统一采用 12 月月度观测，明确价格口径、单位、基期和不计项目 |
| 数据缺少可复核的发布链 | 手抄或临时接口更新会使不同玩家结果不一致 | 冻结原始 CSV、版本和哈希，生成年度表，复核官方表格；禁止填补缺失年份 |
| 原始存档资产可被直接修改 | 自报财富会让排行榜失去基本意义 | 存档与成绩只接受合法选择记录，按固定规则重算资产 |
| 跨场景直接比财富不公平 | 国家货币、出生家庭、历史和运气各不相同 | 好友榜按同一人生编号分组，分财富、现金缓冲、生活三项查看 |
| 终局只有一个金额 | 玩家看见输赢，却不理解后果 | 提供全程日志、账本解释、现金目标、两条净资产/购买力曲线和只改一次的回放 |
| 长页面易使手机操作复杂 | 查资料、看图表挤占主要决定 | 每次只处理一个核心选择，长账本与史料折叠，三项工具入口统一 |
| 失败场景缺少说明 | 清缓存、导入坏档、另开标签容易丢进度 | 独立版本存档、有效备份、输入校验、冲突提醒、导出导入和复制分享兜底 |

## 与原始需求逐项对应

| 需求 | 本版实现与边界 |
| --- | --- |
| 全球随机出生 | 日本、美国、英国、加拿大；出生年份和家庭随机，成年后开始 30 年玩法。支持 4 国，不宣称覆盖所有国家 |
| 60 次快速选择 | 30 个年度，每年生活与资产各一次；状态机明确记为 60 次有效选择。可以分次续玩 |
| 真实历史经济与行情 | 11 个 OECD/FRED 序列及有出处的央行历史节点，明确区分真实行情与虚构家庭故事 |
| 资产配置的专业性 | 现金需求、分散、汇率、物价、保障和长期投入都有可解释结果，不预设“专业路线必赚更多” |
| 智能体模拟交易 | 财务助理按规则解释和执行配置，无在线模型费用；不把确定规则说成预测型大模型 |
| 婚姻、孩子、意外 | 关系与家庭支出进入状态，后续事件读取先前标记；没有强迫所有角色进入同一家庭路径 |
| 重玩和比较 | 同开局重玩；只改一个年度的配置，固定其他选择和外生意外后重算 |
| 好友排行榜 | 用户确认采用成绩链接汇总；导入后重算、分场排序、榜单快照分享，无自动云同步 |
| 可直接公开使用 | 保持现有 GitHub Pages 地址，零注册、无后端依赖、手机与桌面支持 |
| 完整玩法说明 | 独立网页、Markdown 源文件；包括规则、金额单位、结算示例、好友流程、数据和限制 |

Word 中的 Cocos、微信 AppID、广告、登录和奖励接口是后续平台化方案，不是已经获授权的线上微信产品要求。当前明确交付的是浏览器游戏，原生微信小游戏上架、支付和广告没有被伪称为完成。

## 开源参考：采用什么思想，为什么不直接堆依赖

本轮核对了项目的公开仓库与 README。它们提供组织方法，不证明原《中国式人生》的内部源码或引擎。没有复制原游戏的私有程序、人物素材或事件文本。

| 项目 | 可借鉴内容 | 本项目的取舍 |
| --- | --- | --- |
| [VickScarlet/remake](https://github.com/VickScarlet/remake)（原 lifeRestart） | 年龄、事件、条件和独立数据组织；当前项目为 MIT 许可 | 借鉴状态与事件分离。重写原创家庭剧情与金融规则，不把自动事件抽取误认为玩家选择系统 |
| [inkjs](https://github.com/y-lohse/inkjs) | 将互动叙事与前端呈现分开，适合较复杂的分支文字 | 当前 30 年事件使用明确、受限的配置。未引入额外叙事运行时；若未来大幅增加长剧情，再评估接入 |
| [boardgame.io](https://github.com/boardgameio/boardgame.io) | 基于动作的状态转换、阶段控制、日志与多人状态管理 | 采用纯规则与合法命令模式。用户选择静态成绩汇总，因此当前无需实时多人网络层 |

本版规则、内容、数据、图表、分享协议和界面各自分离。浏览器直接执行静态文件，运行时不依赖这些开源框架，也没有把它们的演示代码当作自己的商业后端。

## 数据质量：可以证明什么

数据发布链为：官方原始 CSV → 完整性与日期校验 → 43 个年度观测点 → 固定数据版本 → 规则重放 → 图表与账本。

11 个原始序列各有 43 个完整的 12 月观测，合计 473 个来源观测值；美国本币兑美元恒为 1，不冒充额外的外部数据序列。每条序列的 SHA-256 随版本保存。

另从 FRED 官方 HTML 数据表核对 1978、1988、1990、2008、2020 五个年份，共 55 个值，按显示精度与原始 CSV 比较。它验证了接口提取与单位对应，属于同一个上游来源的两种格式交叉检查，不能表述为两个独立经济数据供应商确认。

对日本 CPI 的已选序列，2021 年以后的全年 12 月数据不完整。本版因此限定最晚从 1990 年开始并在 2020 年结束，没有补造后续数字。未来扩展年代时，应先选择兼容的新数据序列并发布新的数据版本，不应静默拼接。

OECD 的[股价指标定义](https://www.oecd.org/en/data/indicators/share-prices.html)区分价格指数与包含股息再投资的回报指数。本版使用价格口径。跨国组合使用实际汇率观测，公式和本币方向写入测试；不把跨国股价直接相加，也不忽略英镑兑美元的方向。

## 确定性、账本与分享的可信边界

规则核心不读取网络或当前时间，不调用 Math.random。外生事件按人生编号和年份独立生成；界面刷新不会重新抽签，另一种配置也不会改变下一年发生什么。

每次命令需要匹配当前 revision 与阶段。生活选择和资金安排必须交替，完成第 60 次后不能继续提交普通动作。存档记录规则版本、数据版本、编号与命令；导入时从头重算，不相信存档中的自填余额。

每年都检查资产守恒：期初净资产减即时支出，加市场损益与收支结余，减自付账单，必须等于期末净资产。现金与股票持仓不得为负，债务明确单列，金额为整数本币单位。

成绩分享同样从合法命令计算。这样能拒绝乱填余额、越界比例、错误版本和未完成的成绩，但不能阻止玩家查看历史后重玩、搜索最优路径或借用昵称。没有服务器身份认证，不能称作竞赛级防作弊。

## 本轮验收与运营建议

规则测试覆盖 2,048 局完整人生、122,880 次选择，以及全部 36 种国家年代家庭组合；另有逐步保存恢复、重复提交、延后技能、育儿期限、保障、汇率组合、反事实一致性、坏数据和分享协议测试。

手机界面按完整路径验证，而不仅检查首页。关注 320/390 像素窄屏、桌面、刷新续玩、复制受限、导入导出、两台独立浏览器之间的成绩链接和好友榜，以及上线后的同一路径。

发布时只上传独立游戏白名单文件。主项目的其他研究材料、账号信息、用户存档与原始私人调研附件均不随站点发布。经典日本篇保留入口；旧规则与旧存档不会被新算法静默改写。发布保留 Git 提交，必要时可以回退到上一版本。

面向老师和同学的首轮体验，优先记录：60 次选择完成率、在哪一阶段停止、是否理解现金缓冲、是否能解释反事实比较、是否区分价格变化与家庭净资产、是否能自行完成好友分享。当前没有上传行为数据或第三方跟踪；这些反馈应由体验者自行提供。

## 仍然存在的产品局限

这些边界不妨碍当前静态网页试玩，但不能在后续汇报中省略：

- 全球篇支持四国，家庭与职业剧情仍以通用情境为主，未覆盖各国完整税制、教育、医疗、养老金和法律制度。
- 年度结算无法表现月内现金压力；工资参数是教学假设，现金、债务均不计利息，股票不计股息与交易税费。
- 数据使用当前修订后的冻结历史值，不是完整的当年信息发布时点数据库。CPI 的发布时间滞后也未精确模拟。
- 股价路径与新闻史料能够并列回看，不能证明某一条新闻单独造成某个价格变化。
- 生活满意度可达到上限，不能作为真实幸福测量，也不能代表“人生胜负”。
- 成绩榜依赖链接汇总，不能自动同步所有朋友的新增记录；昵称未认证，不适合设置有价值奖品的竞赛。
- 自动化与浏览器测试说明功能按规则工作，不能代替目标人群的可玩性和教育效果验证。

后续若要进入自动云同步或正式竞赛，才需要引入身份、服务器命令验证、数据库事务、限流和数据删除机制；若进入正式金融机构使用或原生微信平台，则应针对该渠道与用途单独完成内容、数据授权和平台接入评估。这些都不应以“网页已经上线”替代。
