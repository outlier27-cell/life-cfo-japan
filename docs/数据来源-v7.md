# 家庭账本篇数据来源与估值规则

## 第八版 · 年度简报

第八版把「年末简报 → 配置 → 月度结算」串成一轮。每年主要确认一次，最多 30 次。简报由本地公开事件或本地统计、全球或政策新闻、已知家庭消息组成。读者可以展开按人生编号固定抽取的住房、黄金汇率或利率观察。资料以当年年底为截止时间；未来行情与突发账单在结算时揭晓。历史节点与家庭事件图片沿用已校对的档案、写实复原及情境图。

添丁后仍租房、跨年失业、长期照护时，配置里可能出现一项可选家庭应对。可以继续现状，也能安排租大一些的住处、投入短期培训或安排家庭轮班。费用纳入一次配置确认。租房与购房不能同时选；培训缩短预设的等待时间；家庭轮班减少照护期间月支出。裁员、事故与中奖等继续由人生编号和年份抽取。房车和保险会改变哪些账单实际落到家庭。相同模式、年份和编号使用相同的可复现抽样。

结算把年初估算与实际收入、必要开支、账单、本地市场和持仓损益并排呈现。未购房时显示同规格住房的首付加费用门槛变动。完整月度现金账和净资产可导出。终局默认只看我的配置、固定均衡、本地股指。本地股指使用同币种价格指数、不含股息，开局等于 100，展示完整 30 年。家庭净资产也按开局归一，曲线停在实际终止年份。其他模型在展开区。仍可重算某个关键年度，保留原局及成绩。

第八版成绩与旧玩法分别汇总。明确指定旧版及人生编号的链接继续进入原模式，同一浏览器已有存档可继续。

## 7.3 月度现金流

7.3 旧版使用月度现金流模式。手机上每年只需确认一次配置。开局看总资产、负债和净资产，配置时可查看手头现金及三个月、六个月必要支出的金额。年初只显示已知历史，年末展示刚结束的一年的历史影像和家庭事件。

工资、生活费、房贷、临时账单和赔款按月入账。月内先应用当月市场价格，再记到账工资和已排定的赔付、固定支出及同月事件。同月事件采用固定顺序，月度行情无法推断日内价格。缺现金先卖债券、再卖黄金、最后卖股票。急售股票有额外 5% 折价。付不起的部分进入欠款，后续收入先清欠。年末仍有未付账单或资不抵债时进入危机处置。房贷按既有年度等额年供算出本年本金和利息，再分摊到 12 个月，首尾月份按整数分配。

出生、入学、照护、裁员、复工、调岗、个人意外和奖励会自动发生。住房或车辆维修只在持有相关资产时生效。医疗费先垫付，两个月后按投保合同赔付，赔款可以跨年。同编号和模式使用相同外部事件，家庭状态或持仓可以改变后果。家中新添人口会带来搬家费和育儿开支，买房仍由玩家决定。

年末可查看现金走势、事件图和逐月实付线索。终局列出最低现金月份、急售折价和欠款，并允许重算任一已结算年份。重算沿用原年初状态和事件，只更换投资配置。涉及危机的年份，两列比较处置前结果。重算对原有成绩无影响。

7.2 年度结算和故事玩法继续按各自规则回放，三种成绩分开排名。历史档案、写实历史复原和家庭情境图各有标注。新增 15 张家庭情境图由制作端通过 OpenAI Image API 生成，网页使用静态 WebP。

## 旧版和通用规则

7.2 新开局由 mode=auto 标识。收入与账单事件使用编号与年份的确定性抽样，年度配置前只展示已知搬家费。自动模式的急售股票额外折价 5%，损失进入原有费用和现金收付字段。旧故事模式保持原事件及结算，存档和成绩按模式重放。新增 10 张写实历史复原使用 OpenAI Image API 的 gpt-image-2 批量生成，提示词与哈希见 assets/history/extra-prompts.jsonl 和 extra-manifest.json。

## 股票、黄金与汇率

本地股票因子 = 当月价格指数 ÷ 上月价格指数。采用OECD月度价格口径，通常是月均值，不是年末收盘，不含股息。四国股票在每年起点按四国等权建立参考组合，年内相对价格变化来自固定的初始份额；它不是历史上实际存在的基金。

外国市场的本币累计因子 = 外国股价累计因子 ×（当前玩家本币/美元 ÷ 当前该国本币/美元）÷（年初玩家本币/美元 ÷ 年初该国本币/美元）。四国起点各25%，将四个本币累计因子求平均，再用相邻月的累计因子之比计算月变化。

黄金本币月因子 = 本月黄金美元价 ÷ 上月黄金美元价 × 本月本币/美元 ÷ 上月本币/美元。没有汇率对冲、利息或股息。

[OECD股价定义](https://www.oecd.org/en/data/indicators/share-prices.html) · [世界银行商品市场与数据使用说明](https://www.worldbank.org/en/research/commodity-markets)
## 国债模型：收益率不是收益

数据是美联储H.15的GS10，月度营业日平均、年化百分比。每年起点建立面值100美元、剩余期限10年的教学平价债，年票息金额等于起点收益率百分数；每半年付息，年底重新建立下一年的10年债参考。

在年内第m个月，使用当月GS10作为整个剩余现金流的统一折现率：

P(m) = Σ [票息/2 + 到期本金] ÷ (1 + 当月年化收益率/2)^(2 × 剩余年数)。

式中的收益率使用小数，如5%为0.05。只包含观察时点之后的现金流；当月已付票息另加。月度美元持有因子 = [当月剩余现金流价格 + 当月票息] ÷ 上月价格，再乘本币汇率因子。票息视作再投资。

这是平坦收益率曲线、合成期限滚动和理想化再投假设下的估值，不是国债实际成交价或某只总回报指数。利率上涨时，固定票息债券可能跌价。

[美联储GS10数据与口径](https://fred.stlouisfed.org/series/GS10) · [美国SEC投资者教育：债券](https://www.investor.gov/introduction-investing/investing-basics/investment-products/bonds-or-fixed-income-products/bonds)
## 房产、车辆、现金和保险

住房：BIS名义住宅价格指数，国家口径，2010=100，选Q4。开局金额锚定120个月教学基础预算，以后按指数比例变化。国家之间的房屋覆盖类型和编制方法仍有差异。首付30%、固定5%房贷、按20年计算的年供（取整可能产生次年尾款）、3%买卖费等均为教学合同；不是历史当地利率或城市房价。

汽车：BLS美国新车CPI，1982—1984=100、非季调。开局金额锚定8个月基础预算，以后按美国价格指数和本币/美元汇率变化，作为统一的进口车成本参考；持有车辆每年再扣15%教学折旧。它不是当地车型报价，也不是二手车交易指数。养车支出另计。

现金：本币不计息，实际购买力用CPI折算。保险：0/50/80%模拟医疗账单保障，保费0/0.6/1.2个月预算，没有现金价值；未声称模拟真实当地保险产品。人物、收入、医疗金额与维修意外均属虚构情境。

## 执行时点与可用信息

每年决策页只显示刚过去的年份；固定模型使用公开比例，现金流管家使用当前已知预算与责任；均不读取下一年。月均价、季度价格与CPI存在统计发布时间和后续修订，本版未完整还原实时信息可得性；使用固定的2026-11-13历史快照。

7.0仅在年初按本次确认比例调整金融资产，年内没有止盈止损或自动再平衡；月度观测用于估值。家庭工资与费用按年度净额结算，不能还原逐月账单和发薪的先后。新闻是史料改写，不证明某条消息单独造成价格变化。
## 家庭账本和危机处置

年度收支差额为收入及遗产减去本年应承担的生活、保障、选择费用、房贷还款与自付账单。它不等于现金或净资产。现金不足先出售债券、黄金、股票并计费；仍有欠款或净资产为负时，必须进入危机处理，无法清偿则结束。现金图只把实际支付列为现金流出，欠款留在负债栏。具体顺序和恒等式见开发文档。

## 事前压力测试的参数

基础篇保留三个可选固定假设，股票/债券/黄金分别变化-25%/-5%/-10%、-20%/-12%/0%、0%/0%/0%；账单分别为3个月医疗、2个月维修、3个月医疗基础预算。均按本币作用，没有历史概率或预测含义。先处理当前计划与费用，再施加一次冲击，预留全年保费并支付旧欠款与自付账单。不计未来收入和房车涨跌；实际年度按family-7.0.0规则结算。具体顺序见[开发文档](developer.html)与[玩法](guide.html)。

## 7 0版账本核验与历史图

30年总览只显示已经结算的金额，未来及终止后的年份留空。玩家与三个模型使用相同编号、外部事件和生活选择，每年都可按同一个年末对照；模型先终止时不补后续值。现金流图的资产收付来自独立记录的变现、配置、房车与偿债现金变化，另行验证现金恒等式，不以年末余额倒算残差。

决策图使用截至已知年末的13个观测，显示过去12个月的本地股票价格和本币黄金价格，首期各归一为100。月末标签指该月份观测，股票和黄金基础序列含月均口径，不能解释为当月最后一个交易日成交价。年代影册覆盖 1978 至 2020 年。同年档案影像可能记录与正文不同的历史事件，具体主题以照片说明为准。未收录档案的年份使用带标注的 GPT 历史情境插画。家庭故事图片在图注中标为 AI 剧情图。

现金流管家按6、9、12个月必要支出加已知收入缺口确定现金目标，计入计划与交易费后试算；无法满足时提示不足。规则、事件和公式详见[开发文档](developer.html)。数据快照及18条来源序列未因本轮界面、剧情改造而改变。
